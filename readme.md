# Three.js: rotating ball and timers

**Watermelon and timers rotate and react on hover**

Live website: https://2-ball-shtyka.netlify.app/

---

### Install

```bash
npm i
```

<br/>

### Run local server

```bash
npm run dev
```

<br />
